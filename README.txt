MISE EN LIGNE GRATUITE AVEC GITHUB PAGES
1. Créez un compte GitHub si nécessaire.
2. Créez un nouveau dépôt public nommé entre-nous.
3. Ajoutez les 5 fichiers web à la racine du dépôt.
4. Dans Settings > Pages, choisissez Deploy from a branch.
5. Sélectionnez main et /(root), puis Save.
6. Ouvrez l'adresse GitHub Pages obtenue sur Android.
7. Dans Chrome : menu ⋮ > Ajouter à l'écran d'accueil / Installer l'application.
